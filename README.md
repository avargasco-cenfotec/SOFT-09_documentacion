# SOFT-09_documentacion
Introducción a la Ingeniería del Software

Desarrollo de la práctica II del curso Introducción a la Ingeniería del Software

El propósito es aprender sobre Git y GitLab, así como su uso.

Implementar los conceptos y los procedimientos fundamentales 
de la ingeniería del software para la propuesta de productos o 
servicios computacionales, empleando una metodología de 
desarrollo de software que se adapte a los requerimientos de los 
clientes y los usuarios.
